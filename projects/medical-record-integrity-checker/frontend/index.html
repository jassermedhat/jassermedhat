Medical Record Integrity Checker

Educational local Hardhat demo for registering SHA-256 fingerprints of medical records on-chain. Select a role, register a record, verify a file, view patient records, then manage versions or revocation when the selected account is authorized. The blockchain stores the hash and metadata only, never the medical file.

Demo Security Notes

Educational assumptions

Off-chain

Medical files

Files are processed in the browser using the Web Crypto API. Nothing leaves the machine.

On-chain

Hash + metadata

32-byte fingerprint, issuer, patient owner, label, and timestamps are immutably stored.

Versioning

Immutable chain

Updated files add new entries linked to the previous record. Old entries are never deleted.

RBAC

Role separation

Doctors write. Nurses read. Patients view only their own. Admin manages the demo system.
